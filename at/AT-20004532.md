# Verordnung des Bundesministers für Landesverteidigung über die Höhe des Grundbetrages im Auslandseinsatzpräsenzdienst

Präambel/Promulgationsklausel

Auf Grund des § 4 Abs. 3 des Auslandseinsatzgesetzes 2001, BGBl. I Nr. 55, zuletzt geändert durch das Bundesgesetz BGBl. I Nr. 58/2005, wird verordnet:

Die Beträge gebühren ab 1.1.2006 (vgl. § 2 Abs. 1).

§ 1. Der Grundbetrag im Auslandseinsatzpräsenzdienst wird in folgenden betragsmäßigen Höhen festgestellt:

```
Rekrut..............................1.278,30 €
```

```
Gefreiter...........................1.300,33 €
```

```
Korporal............................1.311,34 €
```

```
Zugsführer..........................1.322,36 €
```

```
Wachtmeister........................1.368,68 €
```

```
Oberwachtmeister....................1.391,70 €
```

```
Stabswachtmeister...................1.399,22 €
```

```
Oberstabswachtmeister...............1.513,98 €
```

```
Offiziersstellvertreter.............1.580,70 €
```

```
Vizeleutnant........................1.664,43 €
```

```
Leutnant............................1.603,47 €
```

```
Oberleutnant........................1.657,57 €
```

```
Hauptmann...........................1.755,19 €
```

```
Major...............................2.020,83 €
```

```
Oberstleutnant......................2.245,10 €
```

```
Oberst..............................2.653,36 €
```

```
Brigadier...........................3.367,33 €
```

```
Generalmajor........................4.176,30 €
```

```
Generalleutnant.....................5.281,57 €
```

```
General.............................5.532,93 €
```

§ 2. (1) Die Beträge nach § 1 gebühren ab 1. Jänner 2006.

(2) Mit dem In-Kraft-Treten dieser Verordnung tritt die Verordnung BGBl. II Nr. 9/2005 außer Kraft.
