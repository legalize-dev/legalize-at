# Verordnung der Bundesministerin für Arbeit, Soziales, Gesundheit und Konsumentenschutz über den Aufteilungsschlüssel in der Krankenversicherung der Pensionist/inn/en

Präambel/Promulgationsklausel

Auf Grund des § 73 Abs. 5 des Allgemeinen Sozialversicherungsgesetzes, BGBl. Nr. 189/1955, zuletzt geändert durch das Bundesgesetz BGBl. I Nr. 84/2019, wird verordnet:

Für das Kalenderjahr 2018 wird für die Aufteilung der Beiträge in der Krankenversicherung der Pensionist/inn/en (Rentner/innen) auf die Krankenversicherungsträger folgender endgültiger Aufteilungsschlüssel festgesetzt:

| Wiener Gebietskrankenkasse | 19,54033 |
| --- | --- |
| Niederösterreichische Gebietskrankenkasse | 22,05593 |
| Burgenländische Gebietskrankenkasse | 4,26519 |
| Oberösterreichische Gebietskrankenkasse | 16,66828 |
| Steiermärkische Gebietskrankenkasse | 13,40053 |
| Kärntner Gebietskrankenkasse | 6,71303 |
| Salzburger Gebietskrankenkasse | 5,77986 |
| Tiroler Gebietskrankenkasse | 6,60016 |
| Vorarlberger Gebietskrankenkasse | 3,98498 |
| Betriebskrankenkasse der Wiener Verkehrsbetriebe | 0,00468 |
| Betriebskrankenkasse Mondi | 0,07452 |
| Betriebskrankenkasse voestalpine Bahnsysteme | 0,41546 |
| Betriebskrankenkasse Zeltweg | 0,11923 |
