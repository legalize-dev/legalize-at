# Verordnung des Bundesministers für Landesverteidigung über den Grundbetrag im Auslandseinsatzpräsenzdienst

Präambel/Promulgationsklausel

Auf Grund des § 3 Abs. 3 des Auslandseinsatzgesetzes, BGBl. Nr. 233/1965, zuletzt geändert durch das Bundesgesetz BGBl. I Nr. 87/2000, wird verordnet:

§ 1. Der Grundbetrag im Auslandseinsatzpräsenzdienst wird in folgenden betragsmäßigen Höhen festgestellt:

```
Rekrut ................................................  15 723,80 S
```

```
Gefreiter .............................................  15 994,90 S
```

```
Korporal ..............................................  16 130,45 S
```

```
Zugsführer ............................................  16 266,00 S
```

```
Wachtmeister ..........................................  16 869,44 S
```

```
Oberwachtmeister ......................................  17 152,96 S
```

```
Stabswachtmeister .....................................  17 294,72 S
```

```
Oberstabswachtmeister .................................  18 712,32 S
```

```
Offiziersstellvertreter ...............................  19 536,00 S
```

```
Vizeleutnant ..........................................  20 572,00 S
```

```
Leutnant ..............................................  19 837,30 S
```

```
Oberleutnant ..........................................  20 504,10 S
```

```
Hauptmann .............................................  21 727,90 S
```

```
Major .................................................  25 012,35 S
```

```
Oberstleutnant ........................................  27 791,50 S
```

```
Oberst ................................................  32 844,50 S
```

```
Brigadier .............................................  41 687,25 S
```

§ 2. Die Beträge nach § 1 gebühren ab 1. Jänner 2001.
