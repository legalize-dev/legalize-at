# Verordnung des Bundesministers für Landesverteidigung über die Höhe des Grundbetrages im Auslandseinsatzpräsenzdienst

Präambel/Promulgationsklausel

Auf Grund des § 4 Abs. 3 des Auslandseinsatzgesetzes 2001, BGBl. I Nr. 55, zuletzt geändert durch das Bundesgesetz BGBl. I Nr. 18/2008, wird verordnet:

§ 1. Der Grundbetrag im Auslandseinsatzpräsenzdienst wird in folgenden betragsmäßigen Höhen festgestellt:

```
Rekrut ..........................................  1.343,67 €
```

```
Gefreiter .......................................  1.366,83 €
```

```
Korporal ........................................  1.378,41 €
```

```
Zugsführer ......................................  1.389,99 €
```

```
Wachtmeister ....................................  1.438,63 €
```

```
Oberwachtmeister ................................  1.462,83 €
```

```
Stabswachtmeister ...............................  1.470,77 €
```

```
Oberstabswachtmeister ...........................  1.591,39 €
```

```
Offiziersstellvertreter .........................  1.661,52 €
```

```
Vizeleutnant ....................................  1.749,53 €
```

```
Leutnant ........................................  1.685,54 €
```

```
Oberleutnant ....................................  1.742,41 €
```

```
Hauptmann .......................................  1.844,89 €
```

```
Major ...........................................  2.124,10 €
```

```
Oberstleutnant ..................................  2.359,84 €
```

```
Oberst ..........................................  2.788,96 €
```

```
Brigadier .......................................  3.539,41 €
```

```
Generalmajor ....................................  4.389,82€
```

```
Generalleutnant .................................  5.551,59 €
```

```
General .........................................  5.815,80 €
```

§ 2. (1) Die Beträge nach § 1 gebühren ab 1. Jänner 2008.

(2) Mit dem Inkrafttreten dieser Verordnung tritt die Verordnung BGBl. II Nr. 528/2006 außer Kraft.
