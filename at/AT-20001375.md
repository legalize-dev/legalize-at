# Verordnung des Bundesministers für Landesverteidigung über die Dienstgradzulage

Präambel/Promulgationsklausel

Auf Grund des § 4 des Heeresgebührengesetzes 2001, BGBl. I Nr. 31, in der Fassung des Bundesgesetzes BGBl. I Nr. 56/2001, wird verordnet:

§ 1. (1) Die Höhe der für einen Kalendermonat gebührenden Dienstgradzulage wird durch einen Hundertsatz des Gehaltsansatzes der Gehaltsstufe 2 der Dienstklasse V nach § 118 Abs. 5 des Gehaltsgesetzes 1956, BGBl. Nr. 54, einschließlich allfälliger Teuerungszulagen wie folgt festgesetzt:

```
Dienstgrad                   Hundertsatz
```

```
Gefreiter                      2,28 vH
```

```
Korporal                       2,85 vH
```

```
Zugsführer                     3,41 vH
```

```
Wachtmeister                   4,68 vH
```

```
Oberwachtmeister               5,24 vH
```

```
Stabswachtmeister              5,81 vH
```

```
Oberstabswachtmeister          6,37 vH
```

```
Offiziersstellvertreter        6,94 vH
```

```
Vizeleutnant                   7,50 vH
```

```
Fähnrich                       8,36 vH
```

```
Leutnant                       8,92 vH
```

```
Oberleutnant                   9,47 vH
```

```
Hauptmann                     10,61 vH
```

```
Major                         11,88 vH
```

```
Oberstleutnant                13,00 vH
```

```
Oberst                        14,14 vH
```

```
Brigadier                     15,41 vH
```

```
Divisionär                    15,83 vH
```

```
Korpskommandant               16,25 vH
```

```
General                       16,68 vH
```

(2) Für Anspruchsberechtigte mit einem anders festgesetzten Dienstgrad gilt der Ansatz für den gleichwertigen Dienstgrad.

§ 2. Diese Verordnung tritt mit 1. Juli 2001 in Kraft.
