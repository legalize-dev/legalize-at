# Verordnung des Bundesministers für Arbeit und Soziales, mit der Landeshöchstzahlen für die Beschäftigung von Ausländern für 1994 festgesetzt werden (Landeshöchstzahlenverordnung 1994)

Präambel/Promulgationsklausel

Auf Grund des § 13a Z 3 des Ausländerbeschäftigungsgesetzes, BGBl. Nr. 218/1975, zuletzt geändert durch das Bundesgesetz BGBl. Nr. 502/1993, wird verordnet:

§ 1. Zur Sicherung der Bundeshöchstzahl gemäß § 12a des Ausländerbeschäftigungsgesetzes werden Landeshöchstzahlen für das Jahr 1994 wie folgt festgesetzt:

```
Burgenland ..................................................   3 500
```

```
Kärnten .....................................................   7 800
```

```
Niederösterreich ............................................  31 000
```

```
Oberösterreich ..............................................  32 000
```

```
Salzburg ....................................................  17 000
```

```
Steiermark ..................................................  13 000
```

```
Tirol .......................................................  19 500
```

```
Vorarlberg ..................................................  16 000
```

```
Wien ........................................................  91 000
```

§ 2. Diese Verordnung tritt mit 1. Jänner 1994 in Kraft und mit Ablauf des 31. Dezember 1994 außer Kraft.
