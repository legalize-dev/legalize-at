# Verordnung des Bundesministers für Wissenschaft und Forschung über die Zulassung von Absolventinnen und Absolventen von Fachhochschul-Masterstudiengängen zum Doktoratsstudium

Präambel/Promulgationsklausel

Auf Grund des § 6 Abs. 4 und 5 des Bundesgesetzes über Fachhochschul-Studiengänge (FHStG), BGBl. Nr. 340/1993, zuletzt geändert durch das Bundesgesetz BGBl. I Nr. 79/2013, wird verordnet:

Zulassung zum Doktoratsstudium der technischen Wissenschaften

§ 1. Das Recht auf Zulassung zum Doktoratsstudium der technischen Wissenschaften haben die Absolventinnen und Absolventen der nachstehenden Fachhochschul-Masterstudiengänge:

| Studiengangskennzahl | Bezeichnung |
| --- | --- |
| 0300 | Industrielle Elektronik |
| 0328 | Sportgerätetechnik |
| 0332 | Technisches Umweltmanagement und Ökotoxikologie |
| 0647 | Industrial Design |
| 0712 | Regenerative Energiesysteme und technisches Energiemanagement |
| 0714 | Umwelt-, Verfahrens- Energietechnik |
| 0718 | Aerospace Engineering |
| 0720 0721 | Health Assisting Engineering Applied Image and Signal Processing |
|  |  |

Zulassung zum Doktoratsstudium der Sozial- und Wirtschaftswissenschaften

§ 2. Das Recht auf Zulassung zum Doktoratsstudium der Sozial- und Wirtschaftswissenschaften haben Absolventinnen und Absolventen der nachstehenden Fachhochschul-Masterstudiengänge:

| Studiengangskennzahl | Bezeichnung |
| --- | --- |
| 0622 | International Business |
| 0677 | Training und Sport |
| 0683 | Betriebswirtschaft Wirtschaftspsychologie |
| 0705 | Strategic HR Management in Europe |
| 0707 | Musiktherapie |
| 0719 | Umwelt- und Nachhaltigkeitsmanagement |
| 0722 | Innovationsentwicklung im Social-Profit-Sektor |
|  |  |
