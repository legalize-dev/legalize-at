# Verordnung des Bundesministers für Landesverteidigung über die Höhe des Grundbetrages im Auslandseinsatzpräsenzdienst

Präambel/Promulgationsklausel

Auf Grund des § 4 Abs. 3 des Auslandseinsatzgesetzes 2001, BGBl. I Nr. 55/2001, wird verordnet:

§ 1. Der Grundbetrag im Auslandseinsatzpräsenzdienst wird in folgenden betragsmäßigen Höhen festgestellt:

```
Rekrut .................................................... 15 724 S
```

```
Gefreiter ................................................. 15 995 S
```

```
Korporal .................................................. 16 130 S
```

```
Zugsführer ................................................ 16 266 S
```

```
Wachtmeister .............................................. 16 870 S
```

```
Oberwachtmeister .......................................... 17 153 S
```

```
Stabswachtmeister ......................................... 17 294 S
```

```
Oberstabswachtmeister ..................................... 18 712 S
```

```
Offiziersstellvertreter ................................... 19 537 S
```

```
Vizeleutnant .............................................. 20 572 S
```

```
Leutnant .................................................. 19 837 S
```

```
Oberleutnant .............................................. 20 506 S
```

```
Hauptmann ................................................. 21 727 S
```

```
Major ..................................................... 25 015 S
```

```
Oberstleutnant ............................................ 27 791 S
```

```
Oberst .................................................... 32 845 S
```

```
Brigadier ................................................. 41 683 S
```

```
Divisionär ................................................ 51 800 S
```

```
Korpskommandant ........................................... 65 509 S
```

```
General ................................................... 68 626 S
```

§ 2. Die Beträge nach § 1 gebühren ab 1. Juli 2001.
