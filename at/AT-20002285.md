# Verordnung des Bundesministers für Landesverteidigung über die Höhe des Grundbetrages im Auslandseinsatzpräsenzdienst

Präambel/Promulgationsklausel

Auf Grund des § 4 Abs. 3 des Auslandseinsatzgesetzes 2001, BGBl. I Nr. 55, in der Fassung des Bundesgesetzes BGBl. I Nr. 103/2002 wird verordnet:

§ 1. Der Grundbetrag im Auslandseinsatzpräsenzdienst wird in folgenden betragsmäßigen Höhen festgestellt:

```
Rekrut ................................................... 1 151,8 €
```

```
Gefreiter ................................................ 1 171,6 €
```

```
Korporal ................................................. 1 181,6 €
```

```
Zugsführer ............................................... 1 191,5 €
```

```
Wachtmeister ............................................. 1 235,8 €
```

```
Oberwachtmeister ......................................... 1 256,6 €
```

```
Stabswachtmeister ........................................ 1 266,8 €
```

```
Oberstabswachtmeister .................................... 1 370,7 €
```

```
Offiziersstellvertreter .................................. 1 431,1 €
```

```
Vizeleutnant ............................................. 1 506,9 €
```

```
Leutnant ................................................. 1 453,1 €
```

```
Oberleutnant ............................................. 1 502,2 €
```

```
Hauptmann ................................................ 1 591,5 €
```

```
Major .................................................... 1 832,4 €
```

```
Oberstleutnant ........................................... 2 035,7 €
```

```
Oberst ................................................... 2 405,9 €
```

```
Brigadier ................................................ 3 053,3 €
```

```
Generalmajor ............................................. 3 794,5 €
```

```
Generalleutnant .......................................... 4 798,8 €
```

```
General .................................................. 5 027,1 €
```

§ 2. (1) Diese Verordnung tritt mit 1. Dezember 2002 in Kraft.

(2) Mit Ablauf des 30. November 2002 tritt die Verordnung BGBl. II Nr. 438/2001 außer Kraft.
