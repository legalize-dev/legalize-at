# Verordnung des Bundesministers für Landesverteidigung über die Höhe des Grundbetrages im Auslandseinsatzpräsenzdienst

Die Beträge gebühren ab 1.1.2003 (vgl. § 2).

Präambel/Promulgationsklausel

Auf Grund des § 4 Abs. 3 des Auslandseinsatzgesetzes 2001, BGBl. I Nr. 55, in der Fassung des Bundesgesetzes BGBl. I Nr. 103/2002 wird verordnet:

Die Beträge gebühren ab 1.1.2003 (vgl. § 2).

§ 1. Der Grundbetrag im Auslandseinsatzpräsenzdienst wird in folgenden betragsmäßigen Höhen festgestellt:

```
Rekrut ................................................... 1 182,8 €
```

```
Gefreiter ................................................ 1 203,2 €
```

```
Korporal ................................................. 1 213,3 €
```

```
Zugsführer ............................................... 1 223,5 €
```

```
Wachtmeister ............................................. 1 266,3 €
```

```
Oberwachtmeister ......................................... 1 287,6 €
```

```
Stabswachtmeister ........................................ 1 294,7 €
```

```
Oberstabswachtmeister .................................... 1 400,9 €
```

```
Offiziersstellvertreter .................................. 1 462,6 €
```

```
Vizeleutnant ............................................. 1 540,1 €
```

```
Leutnant ................................................. 1 483,7 €
```

```
Oberleutnant ............................................. 1 533,7 €
```

```
Hauptmann ................................................ 1 624,9 €
```

```
Major .................................................... 1 870,8 €
```

```
Oberstleutnant ........................................... 2 078,5 €
```

```
Oberst ................................................... 2 456,4 €
```

```
Brigadier ................................................ 3 117,4 €
```

```
Generalmajor ............................................. 3 874,3 €
```

```
Generalleutnant .......................................... 4 899,6 €
```

```
General .................................................. 5 132,8 €
```

§ 2. (1) Die Beträge nach § 1 gebühren ab 1. Jänner 2003.

(2) Mit dem In-Kraft-Treten dieser Verordnung tritt die Verordnung BGBl. II Nr. 414/2002 außer Kraft.
