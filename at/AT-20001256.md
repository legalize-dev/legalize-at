# Kundmachung des Bundeskanzlers betreffend die Verlängerung des Internationalen Tropenholz-Übereinkommens von 1994 und dessen Geltungsbereich

Nach Mitteilung des Generalsekretärs der Vereinten Nationen hat der Internationale Tropenholzrat auf seiner in Lima, Peru, am 30. Mai 2000 stattgefundenen 28. Tagung das Internationale Tropenholz-Übereinkommen von 1994 (BGBl. III Nr. 124/1997) gemäß dessen Art. 46 Abs. 2 bis 31. Dezember 2003 verlängert.

Nach weiteren Mitteilungen des Generalsekretärs haben folgende weitere Staaten ihre Ratifikations- bzw. Beitrittsurkunden hinterlegt:

| Staaten: | Datum der Hinterlegung der |
| --- | --- |
|  | Ratifikations- bzw. Beitrittsurkunde: |
| Ägypten | 13. April 2000 |
| Brasilien | 28. November 1997 |
| Côte d’Ivoire | 31. Jänner 1997 |
| Griechenland | 13. Oktober 1997 |
| Guyana | 27. August 1997 |
| Irland | 18. August 2000 |
| Italien | 25. Juni 1998 |
| Kolumbien | 16. August 1999 |
| Portugal | 4. November 1999 |
| Spanien | 15. Jänner 1997 |
| Suriname | 24. August 1998 |
| Trinidad und Tobago | 29. Dezember 1998 |
| Vanuatu | 19. Mai 2000 |
| Venezuela | 2. März 1998 |
|  |  |

Ferner haben Nepal und die Zentralafrikanische Republik dem Generalsekretär am 23. Mai 1997 die provisorische Anwendung des Übereinkommens notifiziert.
