# Verordnung des Bundesministers für Landesverteidigung über die Höhe des Grundbetrages im Auslandseinsatzpräsenzdienst

Die Beträge gebühren ab 1.7.2003 (vgl. § 2).

Präambel/Promulgationsklausel

Auf Grund des § 4 Abs. 3 des Auslandseinsatzgesetzes 2001, BGBl. I Nr. 55, in der Fassung des Bundesgesetzes BGBl. I Nr. 103/2002 wird verordnet:

Die Beträge gebühren ab 1.7.2003 (vgl. § 2).

§ 1. Der Grundbetrag im Auslandseinsatzpräsenzdienst wird in folgenden betragsmäßigen Höhen festgestellt:

```
Rekrut ..................................................  1 194,6 €
```

```
Gefreiter ...............................................  1 215,2 €
```

```
Korporal ................................................  1 225,5 €
```

```
Zugsführer ..............................................  1 235,8 €
```

```
Wachtmeister ............................................  1 279,0 €
```

```
Oberwachtmeister ........................................  1 300,5 €
```

```
Stabswachtmeister .......................................  1 307,6 €
```

```
Oberstabswachtmeister ...................................  1 414,9 €
```

```
Offiziersstellvertreter .................................  1 477,2 €
```

```
Vizeleutnant ............................................  1 555,5 €
```

```
Leutnant ................................................  1 498,5 €
```

```
Oberleutnant ............................................  1 549,1 €
```

```
Hauptmann ...............................................  1 640,3 €
```

```
Major ...................................................  1 888,6 €
```

```
Oberstleutnant ..........................................  2 098,2 €
```

```
Oberst ..................................................  2 479,7 €
```

```
Brigadier ...............................................  3 146,9 €
```

```
Generalmajor ............................................  3 903,0 €
```

```
Generalleutnant .........................................  4 935,9 €
```

```
General .................................................  5 170,8 €
```

§ 2. (1) Die Beträge nach § 1 gebühren ab 1. Juli 2003.

(2) Mit dem In-Kraft-Treten dieser Verordnung tritt die Verordnung BGBl. II Nr. 178/2003 außer Kraft.
