# Verordnung des Bundesministers für Arbeit und Soziales, mit der Landeshöchstzahlen für die Beschäftigung von Ausländern für 1995 festgesetzt werden (Landeshöchstzahlenverordnung 1995)

Präambel/Promulgationsklausel

Auf Grund des § 13a Z 3 des Ausländerbeschäftigungsgesetzes, BGBl. Nr. 218/1975, zuletzt geändert durch das Bundesgesetz BGBl. Nr. 450/1994, wird verordnet:

§ 1. Zur Sicherung der Bundeshöchstzahl gemäß § 12a des Ausländerbeschäftigungsgesetzes werden Landeshöchstzahlen für das Jahr 1995 wie folgt festgesetzt:

```
Burgenland .................................................  3 100
```

```
Kärnten ....................................................  7 000
```

```
Niederösterreich ........................................... 27 600
```

```
Oberösterreich ............................................. 28 500
```

```
Salzburg ................................................... 15 000
```

```
Steiermark ................................................. 11 600
```

```
Tirol ...................................................... 17 400
```

```
Vorarlberg ................................................. 14 300
```

```
Wien ....................................................... 81 000
```

§ 2. Diese Verordnung tritt mit 1. Jänner 1995 in Kaft (Anm.: richtig: Kraft) und mit Ablauf des 31. Dezember 1995 außer Kraft.
