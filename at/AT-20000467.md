# Verordnung des Bundesministers für Landesverteidigung über den Grundbetrag im Auslandseinsatzpräsenzdienst

Präambel/Promulgationsklausel

Auf Grund des § 3 Abs. 3 des Auslandseinsatzgesetzes, BGBl. Nr. 233/1965, zuletzt geändert durch das Bundesgesetz BGBl. I Nr. 67/1999, wird verordnet:

§ 1. Der Grundbetrag im Auslandseinsatzpräsenzdienst wird in folgenden betragsmäßigen Höhen festgestellt:

```
Rekrut                        15 143,80 S
```

```
Gefreiter                     15 404,90 S
```

```
Korporal                      15 535,45 S
```

```
Zugsführer                    15 666,00 S
```

```
Wachtmeister                  16 274,44 S
```

```
Oberwachtmeister              16 547,96 S
```

```
Stabswachtmeister             16 684,72 S
```

```
Oberstabswachtmeister         18 052,32 S
```

```
Offiziersstellvertreter       18 876,00 S
```

```
Vizeleutnant                  19 877,00 S
```

```
Leutnant                      19 242,30 S
```

```
Oberleutnant                  19 889,10 S
```

```
Hauptmann                     21 297,90 S
```

```
Major                         24 517,35 S
```

```
Oberstleutnant                27 241,50 S
```

```
Oberst                        32 194,50 S
```

```
Brigadier                     40 862,25 S
```

§ 2. die Beträge nach § 1 gebühren ab 1. Jänner 2000.
