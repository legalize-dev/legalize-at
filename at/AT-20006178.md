# Verordnung des Bundesministers für Landesverteidigung über die Höhe des Grundbetrages im Auslandseinsatzpräsenzdienst

Die Beträge gebühren ab 1.1.2009 (vgl. § 2 Abs. 1).

Präambel/Promulgationsklausel

Auf Grund des § 4 Abs. 3 des Auslandseinsatzgesetzes 2001, BGBl. I Nr. 55, zuletzt geändert durch das Bundesgesetz BGBl. I Nr. 18/2008, wird verordnet:

Die Beträge gebühren ab 1.1.2009 (vgl. § 2 Abs. 1).

§ 1. Der Grundbetrag im Auslandseinsatzpräsenzdienst wird in folgenden betragsmäßigen Höhen festgestellt:

Rekrut .............................................   1.391,39 €
```

```
Gefreiter ..........................................   1.415,37 €

```

```

```

```

```

```

```
Oberwachtmeister ...................................   1.514,72 €
```

```
Stabswachtmeister ..................................   1.522,98 €
```

```
Oberstabswachtmeister ..............................   1.647,89 €
```

```
Offiziersstellvertreter ............................   1.720,50 €
```

```
Vizeleutnant .......................................   1.811,64 €
```

```

```

```

```

```

```

```
Major ..............................................   2.199,52 €
```

```
Oberstleutnant .....................................   2.443,62 €
```

```
Oberst .............................................   2.887,98 €
```

```
Brigadier ..........................................   3.665,08 €
```

```
Generalmajor .......................................   4.545,63 €
```

```
Generalleutnant ....................................   5.748,63 €
```

```
General ............................................   6.022,22 €
```

§ 2. (1) Die Beträge nach § 1 gebühren ab 1. Jänner 2009.

(2) Mit dem Inkrafttreten dieser Verordnung tritt die Verordnung BGBl. II Nr. 41/2008 außer Kraft.
