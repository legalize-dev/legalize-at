# Verordnung des Bundesministers für Soziales, Gesundheit, Pflege und Konsumentenschutz über den Aufteilungsschlüssel in der Krankenversicherung der Pensionist/inn/en

Präambel/Promulgationsklausel

Auf Grund des § 73 Abs. 5 des Allgemeinen Sozialversicherungsgesetzes, BGBl. Nr. 189/1955, zuletzt geändert durch das Bundesgesetz BGBl. I Nr. 105/2020, wird verordnet:

Für das Kalenderjahr 2019 wird für die Aufteilung der Beiträge in der Krankenversicherung der Pensionist/inn/en (Rentner/innen) auf die Krankenversicherungsträger folgender endgültiger Aufteilungsschlüssel festgesetzt:

| Wiener Gebietskrankenkasse | 19,09956 |
| --- | --- |
| Niederösterreichische Gebietskrankenkasse | 22,08457 |
| Burgenländische Gebietskrankenkasse | 4,32590 |
| Oberösterreichische Gebietskrankenkasse | 16,76627 |
| Steiermärkische Gebietskrankenkasse | 13,48747 |
| Kärntner Gebietskrankenkasse | 6,76970 |
| Salzburger Gebietskrankenkasse | 5,81917 |
| Tiroler Gebietskrankenkasse | 6,64603 |
| Vorarlberger Gebietskrankenkasse | 4,02759 |
| Betriebskrankenkasse der Wiener Verkehrsbetriebe | 0,00457 |
| Betriebskrankenkasse Mondi | 0,07449 |
| Betriebskrankenkasse voestalpine Bahnsysteme | 0,40815 |
| Betriebskrankenkasse Zeltweg | 0,11841 |
| Betriebskrankenkasse Kapfenberg | 0,31717 |
| Versicherungsanstalt für Eisenbahnen und Bergbau | 0,05095 |
