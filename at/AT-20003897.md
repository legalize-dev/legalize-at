# Verordnung des Bundesministers für Landesverteidigung über die Höhe des Grundbetrages im Auslandseinsatzpräsenzdienst

Die Beträge gebühren ab 1.1.2005 (vgl. § 2).

Präambel/Promulgationsklausel

Auf Grund des § 4 Abs. 3 des Auslandseinsatzgesetzes 2001, BGBl. I Nr. 55, zuletzt geändert durch das Bundesgesetz BGBl. I Nr. 137/2003, wird verordnet:

Die Beträge gebühren ab 1.1.2005 (vgl § 2).

§ 1. Der Grundbetrag im Auslandseinsatzpräsenzdienst wird in folgenden betragsmäßigen Höhen festgestellt:

```
Rekrut ................................. 1 244,73 Euro
```

```
Gefreiter .............................. 1 266,18 Euro
```

```
Korporal ............................... 1 276,91 Euro
```

```
Zugsführer ............................. 1 287,64 Euro
```

```
Wachtmeister ........................... 1 332,69 Euro
```

```
Oberwachtmeister ....................... 1 355,11 Euro
```

```
Stabswachtmeister ...................... 1 362,43 Euro
```

```
Oberstabswachtmeister .................. 1 474,17 Euro
```

```
Offiziersstellvertreter ................ 1 539,13 Euro
```

```
Vizeleutnant ........................... 1 620,67 Euro
```

```
Leutnant ............................... 1 561,30 Euro
```

```
Oberleutnant ........................... 1 613,98 Euro
```

```
Hauptmann .............................. 1 709,08 Euro
```

```
Major .................................. 1 967,74 Euro
```

```
Oberstleutnant ......................... 2 186,12 Euro
```

```
Oberst ................................. 2 583,65 Euro
```

```
Brigadier .............................. 3 278,86 Euro
```

```
Generalmajor ........................... 4 066,51 Euro
```

```
Generalleutnant ........................ 5 142,71 Euro
```

```
General ................................ 5 387,47 Euro
```

§ 2. (1) Die Beträge nach § 1 gebühren ab 1. Jänner 2005.

(2) Mit dem In-Kraft-Treten dieser Verordnung tritt die Verordnung BGBl. II Nr. 65/2004 außer Kraft.
